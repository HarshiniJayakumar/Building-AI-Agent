# Building-AI-Agent
1.Order Status: Retrieves order details and delivery status using the customer's order ID.

2.Policy Search: Searches predefined policies to answer questions about returns, refunds, shipping, and warranties.

3.Shipping Calculator: Calculates shipping charges based on the package weight using a predefined formula.

4.Hallucination Prevention: Uses tool results to provide accurate answers and avoids making up information when the required data is unavailable.

5.Consistency Testing: Submits the same question twice and compares both responses to check whether the agent provides consistent answers.

6.Error Handling: Handles API errors and uses a simple fallback mechanism to respond to supported questions when the API is unavailable.
